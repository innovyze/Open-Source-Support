# Import Manhole Survey Photos from Folder

## Script

[UI-ImportManholeSurveyPhotosFromFolder.rb](./UI-ImportManholeSurveyPhotosFromFolder.rb)

## Purpose

Reads a folder of image files named by manhole survey ID and optional bracket index, then:

1. Builds ODIC header-image and attachment CSV files in the **same folder**
2. Writes matching ODIC `.cfg` mapping files
3. Runs ODIC import for header images and attachments on `cams_manhole_survey`

No source CSV is required. The filename stem and optional bracket index define the target survey and image field.

## Filename convention

The filename stem (before any bracket index and extension) is matched using the prompt option below. An optional bracket index selects the target field.

| Filename example | Index | Target |
|------------------|-------|--------|
| `MH001.jpg` | (none) | Location view → `location_image` |
| `MH001 (2).jpg` | 2 | Location view → `location_image` |
| `MH001 (3).jpg` | 3 | Internal view → `internal_image` |
| `MH001 (4).jpg` | 4+ | Attachments blob (`purpose` = **Location Photo**) |
| `MH001 (10).jpg` | 4+ | Attachments blob (`purpose` = **Location Photo**) |

### Matching the filename stem

| Match filename to | Filename stem matches | ODIC import uses |
|-------------------|----------------------|------------------|
| **Survey ID** (default) | Manhole survey `id` | That survey ID |
| **Node ID** | Manhole survey `node_id` | Resolved survey `id` |

When matching by **node ID**:

- The script looks up `cams_manhole_survey.node_id` in the open network.
- If several surveys share the same node ID, the **most recent** survey is used (`when_surveyed`, then `survey_date`, then `date_completed`).
- A warning is written when multiple surveys match the same node ID.
- Files with no matching survey are skipped and reported.

Notes:

- Brackets may include spaces: `MH001 (2).jpg` or `MH001(2).jpg`
- Supported extensions: `.jpg`, `.jpeg`, `.png`, `.gif`, `.tif`, `.tiff`, `.bmp`, `.webp`
- Files starting with `ODIC_` are ignored (generated by a previous run)
- If index 1 and 2 both target `location_image`, the last file processed wins and a warning is written to the console

## Usage

1. Open the relevant Collection Network in InfoAsset Manager.
2. Place all image files in one folder using the naming convention above.
3. Run via **Network → Run Ruby Script…** and select `UI-ImportManholeSurveyPhotosFromFolder.rb`.

### Prompt options

| Field | Description |
|-------|-------------|
| **Image folder** | Folder containing source image files; ODIC output files are also written here |
| **Match filename to** | **Survey ID** or **Node ID** — filename stem matched to survey `id` or `node_id` |
| **Update existing surveys only** | ODIC `Update Only` (recommended) |
| **Run ODIC import after generating CSVs** | Untick to only generate CSV/cfg files |

## Generated files (in image folder)

| File | Contents |
|------|----------|
| `ODIC_Header_Images.csv` | One row per survey, index 1–3 mapped to header image fields |
| `ODIC_Attachments.csv` | One row per index 4+ file |
| `ODIC_Header_Images.cfg` | ODIC mapping for header import |
| `ODIC_Attachments.cfg` | ODIC mapping on `cams_manhole_survey:attachments` |
| `ODIC_HeaderImport_Errors.txt` | ODIC error log for header import (if errors occur) |
| `ODIC_AttachmentsImport_Errors.txt` | ODIC error log for attachments import (if errors occur) |

## ODIC behaviour

- **Image Folder** is set to the selected folder.
- **Import Images** is enabled.
- **Duplication Behaviour** is `Merge` (appends attachment rows for index 4+).
- **Blob Merge** is `false` for both imports.
- Header import uses ODIC table **`ManholeSurvey`**; attachments import uses **`ManholeSurveyAttachments`**.

## Notes

- Target surveys must already exist in the network when **Update Only** is enabled.
- Uses inline CSV writing (no `require 'csv'`) for IAM 2027+ UI Ruby compatibility.
